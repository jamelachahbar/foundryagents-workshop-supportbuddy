---
id: RB-05
title: DNS issues
symptoms: ["some websites do not load", "apps work but browser fails", "DNS timeout"]
synthetic: true
---

1. Use this procedure only when some websites or apps work and others fail. If nothing loads at all, it does not apply.
2. Confirm the line and the modem are healthy first.
3. Ask whether only some websites fail while others load.
4. Ask the customer to restart the affected device and, if needed, the modem once (RB-02).
5. If several devices still fail on the same websites, hand the case over to a human advisor; do not ask the customer to change advanced network settings.
