---
id: RB-08
title: Connecting a new device to Wi-Fi
symptoms: ["device cannot join Wi-Fi", "wrong Wi-Fi password", "network name not visible"]
synthetic: true
---

1. Check the customer selects the right Wi-Fi network name.
2. Ask the customer to read the Wi-Fi password from the label on the modem.
3. Check the device supports the band in use; older devices may only see 2.4 GHz.
4. If only rooms far from the modem fail, follow RB-11.
5. If no device can join, check the line and the modem before anything else.
